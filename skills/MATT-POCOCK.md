# Matt Pocock skills

This directory contains a repository copy of the stable skills from Matt Pocock's `mattpocock/skills` plugin, version 1.3.1. Files are copied from the plugin's `skills/engineering`, `skills/productivity`, and `skills/misc` directories. Skills marked in-progress and the Claude Code-specific `git-guardrails-claude-code` skill are excluded.

The skills are MIT licensed; see [MATT-POCOCK-LICENSE](MATT-POCOCK-LICENSE). Their upstream source is [mattpocock/skills](https://github.com/mattpocock/skills). This is a vendored snapshot: update it by reviewing and copying a newer upstream release into this shared `skills/` directory. The `.claude/skills` junction makes these files available to Claude Code; other agents can read the same committed files from the repository.
